# Проект «Бронь без конфликтов»

Веб-сервис для бронирования ресурсов образовательной организации (переговорные комнаты, проекторы).

## Стек технологий
- **Backend:** Node.js, Express
- **База данных:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Безопасность:** JWT-токены, проверка ролей (user/admin)
- **Целостность данных:** Транзакции, ограничение EXCLUDE на пересечение времени, Idempotency-Key (защита от дублей).

## Функционал
- Вход и выход в систему с использованием JWT.
- Просмотр каталога активных ресурсов.
- Создание бронирования с защитой от пересечений по времени и дублирования запросов.
- Раздел «Мои бронирования» (просмотр и отмена своих будущих записей).
- Панель администратора (просмотр всех броней, отмена чужой брони с указанием причины).

## Правила времени
- Ресурсы доступны с 08:00 до 22:00 по московскому времени.
- Шаг выбора времени: 30 минут, длительность: от 30 минут до 4 часов.
- Отмена доступна только для будущих записей.

## Как запустить проект (Инструкция)
1. Установите PostgreSQL и создайте базу данных `project`.
2. Восстановите структуру и данные из файла `backup.sql` (или выполните скрипты из `migrations.sql`).
3. В корне проекта выполните установку зависимостей: `npm install`.
4. Откройте файл `index.js` и укажите свой пароль от базы данных в настройках `pool`.
5. Запустите сервер командой: `node index.js`.
6. Откройте браузер по адресу: `http://localhost:3000`.
