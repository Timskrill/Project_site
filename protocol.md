# Протокол ручной проверки приложения

| № | Условия и действие | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Вход в систему под учетной записью `user1` | Успешный вход, появление личного кабинета | Успешно, токен выдан |
| 2 | Создание бронирования на свободное время | Успех, бронь отображается в списке "Мои брони" | Бронь создана, ID присвоен |
| 3 | Попытка забронировать то же время на тот же ресурс | Ошибка 409 "Ресурс уже занят в выбранное время" | Ошибка 409 получена, дубль не создан |
| 4 | Повторная отправка запроса на создание с тем же `Idempotency-Key` | Сервер возвращает исходную бронь (тот же ID), без создания дубля | ID совпал, в БД одна запись |
| 5 | Попытка получить доступ к чужой брони | Ошибка 404 (запись не найдена) | Ошибка 404 получена |
| 6 | Попытка обычного пользователя вызвать `/api/admin/bookings` | Ошибка 403 "Доступ запрещен" | Ошибка 403 получена |
| 7 | Вход под `admin`, просмотр панели администратора | Отображается список всех броней с владельцами | Список отображается |
| 8 | Отмена чужой брони администратором без причины | Ошибка 400 "Необходимо указать причину" | Ошибка 400 получена |
| 9 | Отмена брони администратором с указанием причины | Бронь отменена, время освобождено, причина сохранена | Успешно |
| 10 | Восстановление БД из резервной копии `backup.sql` | База развернута, данные (пользователи, брони) на месте | Восстановление успешно в `project_test` |
